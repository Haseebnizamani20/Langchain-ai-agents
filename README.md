A comprehensive, hands-on course to learn LangChain, AI agents, and LangGraph workflows.
This repository covers everything from basic Python prerequisites to building advanced conversational and agentic applications using LLMs.

Course Structure

01_introduction/ – 

02_setup/ – Environment setup and installation instructions.

03_python_prereq/ – Python fundamentals for AI development.

04_pydantic/ – Data validation and modeling using Pydantic.

05_langchain/ – Core LangChain concepts, chains, and utilities.

06_openai_ollama/ – Working with OpenAI and Ollama LLMs.

07_basic_llm_app/ – Building a simple LLM-powered application.

08_conversational_agents/ – Designing conversational agents with memory and context.

09_agents_vs_agentic/ – Understanding the difference between standard agents and agentic reasoning.

10_langgraph_intro/ – Introduction to LangGraph for structured reasoning.

11_langgraph_components/ – Components and building blocks of LangGraph.

12_debugging_langgraph/ – Debugging and optimizing LangGraph workflows.

13_workflows_in_langgraph/ – Creating end-to-end workflows with LangGraph.

14_human_in_the_loop/ – Integrating human feedback for better AI decision-making.
